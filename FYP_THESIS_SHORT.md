## ABSTRACT

PHARMADICES is a comprehensive web-based medicine information system designed to provide reliable healthcare data to professionals, students, and patients. The system features a database of 1000+ medicines, advanced search functionality, medical store locator, and responsive design optimized for all devices.

**Keywords:** Healthcare Information System, Medicine Database, Web Development, Responsive Design, Medical Store Locator

---

## 1. INTRODUCTION

### 1.1 Background
Healthcare information accessibility remains a significant challenge in Pakistan. PHARMADICES addresses this by providing a centralized, reliable platform for medicine information.

### 1.2 Problem Statement
- Fragmented medicine information across multiple sources
- Limited access to comprehensive healthcare databases
- Lack of integrated medical store location services
- Poor mobile accessibility for healthcare information

### 1.3 Objectives
- Develop comprehensive medicine database (1000+ medicines)
- Implement advanced search and filtering system
- Create interactive medical store locator
- Ensure responsive design for all devices
- Provide educational resource for students

## 4. SYSTEM DESIGN

### 4.1 Database Design
```json

  id, name, brand, generic, type, drugClass,
  uses, dosage, sideEffects, precautions

  services, coordinates
}
```
